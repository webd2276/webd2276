## AI Agents, RAG & Chatbots (Python)

I build AI systems that turn business data into conversational, useful tools: agents that take actions, chatbots that answer from your own documents, and pipelines that connect everything together.

| Project type | How it works | Stack |
| :-- | :-- | :-- |
| **RAG system** | Documents → chunking → embeddings → vector DB → LLM answers with sources | Python · LangChain · ChromaDB / FAISS |
| **Custom chatbot** | Website or WhatsApp message → retrieval → LLM → branded reply | Python · FastAPI · OpenAI / Gemini |
| **AI agent** | Goal → LLM decides → calls tools and APIs → completes the task | Python · LangChain · tool calling |
| **Chat with your data** | Upload PDFs or docs → ask questions → get grounded answers | Python · RAG · Next.js UI |
